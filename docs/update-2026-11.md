# November 2026 source update

This update contains the locally accepted Zombie Survival overhaul. It updates the GitHub source and bundled content; Steam Workshop publication is separate.

## Changes

- Redesigned health, round and boss displays, with translucent panels, retained team faces, one round countdown and resolution-scaled text. F1, shops, weapon selection, scoreboard tooltips and other menus have 1080p and 4K presentation work.
- Shared shop catalogues and validation, separate server checkout/effect modules, bounded network requests, descriptions for zombie buffs and saved Worth carts with failure recovery. Point-shop mouse-exit closing and its delay are client settings.
- Player iteration, bot targeting, entity queries, traces, animation dispatch, timers and network updates have focused allocation and repeated-work reductions. Redeemer income uses combat rewards rather than passive income timers.
- Reworked nail detection, placement, removal and feedback; shared prop-phasing control, collision and safe-exit handling; and preview-owned deployment rotation without dummy ammunition.
- Reworked Shade flashlight interaction and Zombine behavior, namespaced custom weapon/zombie assets, and a project-authored sigil with editable Blender sources.
- Zombie Escape weapon choices, mode-specific HUD/shop availability, boss health display and Mako ending/life-reset handling.
- Progression, key profiles, map voting, traits, returns, repair emitters, Prop Creator, weapon upgrades, cosmetics, guilds and the other applicable open issue implementations.
- A bounded save-data reader that does not execute saved text, while retaining the SRL cart format and improving numeric round-trip precision. Keep existing saves; no JSON migration is required.

## Installation and content

Keep the folder named `zombiesurvival` under `garrysmod/gamemodes`. The runtime files are in `gamemode`, `entities` and `content`; the sigil authoring files under `assets` are optional for running the game. Back up server configuration and persistent data before replacing an existing installation.

The gamemode registers no fixed Workshop dependency by default. Set `zs_content_workshop` to your own content item's numeric ID and, if needed, `zs_gamemode_workshop` to your own gamemode item's ID before starting the map. Each setting accepts one ID; duplicates register once. Ordinary server/FastDL content delivery remains available. Other installed addons can register their own dependencies.

Sabre-aN's skin archive is not bundled. The delivered clothing variant uses project-authored texture work on the existing stock-derived model. Existing contributor and asset credits remain applicable.

D3bot is an optional, separately installed server addon. The gamemode does not install it through Workshop. The [included optimization patch and installation notes](../extras/README.md) reproduce the accepted addon changes from the pinned upstream version.

## Verification scope

The existing local acceptance records cover all ten recorded overhaul requirements and the fourteen applicable open issue implementations. The accepted production snapshot contains 1,009 Lua files. Earlier Windows x64/x86 checks include dedicated servers, single-player/listen hosting, two-client LAN integration, 1080p/4K presentation and actual 128-actor AI combat rounds with normal round restart. Subsequent HUD and serialization changes have their own accepted records and unchanged-component comparisons.

These are scoped results. They do not establish every platform, addon combination, physical-input path, WAN/Steam-account arrangement or a universal 128-slot performance guarantee. Focused operation counts and timing samples do not establish a whole-game FPS improvement percentage. Published Workshop delivery is separate from the verified local/FastDL routes.

No tests or native games were run for this publication review. Current source identity and the existing acceptance records were checked before preparing this update.
